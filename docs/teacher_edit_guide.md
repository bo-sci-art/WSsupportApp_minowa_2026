# 作品の情報の直し方（担任の先生へ）

防災行動マップにのっている作品の「ペンネーム・タイトル・伝えたいこと・場所・いつの行動か」を、先生のPCかiPadで直すことができます。
作品の絵は直せません。

## 1. 管理画面を開く

PC のブラウザ（Chrome・Edge）か、iPad の Safari で、次のアドレスを開きます。

```
https://bo-sci-art.github.io/WSsupportApp_minowa_2026/workshop/present/admin.html
```

防災行動マップの画面の右上にある、小さな歯車（⚙）を押しても開けます。

## 2. 合言葉を入れて入る

1. お伝えした合言葉を入れます。
2. 「入る」を押します。

- 学校のみんなで使うPCやiPadでは、「このPCで覚える」にチェックを付けないでください。
- 「合言葉がちがいます」と出たら、もう一度入れ直してください。
- 使い終わったら、右上の「ログアウト」を押してください。

## 3. 直したい作品をさがす

上の検索の欄に、**ペンネームの一部** か**タイトルの一部**を入れると、その作品だけが出ます。
「場所」の欄で、場所ごとにしぼることもできます。
「並び順」を「ペンネームの順」にすると、ペンネームのあいうえお順にならびます。

## 4. 「確認・修正」を押して直す

1. 作品の行のいちばん右にある「確認・修正」を押します。
2. 作品の絵と、今の情報が出ます。直したいところを書きかえます。
   - **ペンネーム**：本名や、だれの作品かわかる名前になっていたら、ここで直してください（すぐにかくしたいときは「非公開にする」）
   - **タイトル**・**伝えたいこと**：そのまま書きかえる
   - **場所**：6つ（アピタテラス／新綱島駅／コンフォール南日吉／日吉の丘／北綱島ポンプ場／その他）の中から1つ選ぶ
     - アピタテラスなど5つの場所にすると、地図のピンもその場所に移ります
     - 「その他」にすると、下に地図が出ます。**赤い線の中の、ピンを置きたいところをタップ**してください。タップしたところにピンが動きます
     - 「その他」の作品は、地図にもう児童が置いたピンが出ています。ピンの場所を直したいときだけ、地図をタップしてください
     - 「その他」の作品を5つの場所のどれかに変えたときも、児童が置いたピンの位置は記録に残っています。あとで「その他」に戻すと、そのピンの位置から始まります
   - **いつの行動か**：あてはまるものに全部チェックを付ける
3. 直したところは黄色になります。

## 5. 保存する

1. いちばん下の「保存する」を押します。
2. 「変更前 → 変更後」の一覧が出ます。まちがいがないか見てから「保存する」を押します。
3. 「保存しました」と出たら終わりです。一覧の「最終修正」に「修正済み」と日時が出ます。

- 赤い文字が出たときは、書いてあるとおりに直してから、もう一度「保存する」を押してください。
  例：「ペンネームが空です。ペンネームを入れてください。」「『その他』のときは、地図をタップしてピンを置いてください。」
- 直すのをやめるときは「やめる」を押します。直している途中なら「保存せずに閉じますか？」と聞かれます。

## 消すときと、かくすとき

一覧で作品の行を押すとチェックが付きます。下の3つのボタンが使えます。

| ボタン | すること |
|---|---|
| 非公開にする | マップから**かくす**。作品は残っているので、あとで「公開に戻す」で元にもどせる |
| 公開に戻す | かくした作品を、マップにもう一度出す |
| 削除する | 作品を**消す**。**元に戻せません** |

**迷ったときは「削除する」ではなく「非公開にする」を使ってください。** あとで相談してから消すことができます。

## こまったときは

- 画面が古いままのときは、ページを再読み込みしてください。
- 「通信できませんでした」と出るときは、インターネットにつながっているか確かめてください。
- わからないことがあれば、アプリの担当者に連絡してください。
